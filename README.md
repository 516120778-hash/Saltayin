# 萨尔塔音 (Saltayin) - 技术支持与项目主页

## 📖 关于应用
《萨尔塔音》是一款致力于保护和传承“有音无字”东乡语的文化探索 iOS 应用。团队基于田野调查精心收录核心语料，结合端侧人工智能特征比对技术，为大众提供沉浸式的无字乡音探索与跟读体验。

## 🔒 隐私保护说明
保护用户的隐私是我们的首要任务。本应用在使用“发音共鸣度评估”功能时，所有的音频特征提取与比对均在 iOS 设备本地离线完成（On-Device），我们绝对不会收集、上传或存储您的任何语音实体数据。
